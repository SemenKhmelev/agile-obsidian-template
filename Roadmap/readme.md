
Тип итерации зависит от того, сколько нужно времени ее достичь:


* **Vision** - конечная цель в отдаленной перспективе куда хотим прийти в перспективе ~3 лет. Может содержать theme, и под вопросом epic. 
	  Виденье != философия (не бесконечный процесс, aka качественный продукт)
* **Theme** - Перспектива на 1 год. Может содержать епики. Границы ТЗ могут быть немного расплывчаты. Является составной частью Vision
* **Epics** - Блок задач на несколько спринтов (2-3 месяца) с четко понятным финалом и рамками по ТЗ.
* **Task** - Одна конкретная небольшая задача (1-2 спринта). **Task backlog** - каталог для задач не взятых в работу в рамках какого либо спринта
