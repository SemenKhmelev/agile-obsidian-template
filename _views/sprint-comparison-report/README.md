# Отчёт по сравнению спринтов

## Обзор

Это представление формирует отчёт, который сравнивает время, потраченное на "Сопутствующие задачи!" (предопределённые
задачи) в текущем спринте и двух предыдущих. Оно создаёт как табличное представление, так и визуальную столбчатую
диаграмму, чтобы помочь выявить тенденции в распределении времени.

## Возможности

- Получает данные для текущего спринта и двух предыдущих спринтов.
- Фильтрует предопределённые задачи ("Сопутствующие задачи!").
- Создаёт табличное сравнение затраченного времени по спринтам.
- Генерирует визуальную столбчатую диаграмму с цветовой кодировкой.
- Предоставляет аналитические выводы на основе сравнения данных по спринтам.
- Сортирует задачи по времени, затраченному в текущем спринте (по убыванию).
- Обрабатывает случаи, когда задачи могут присутствовать в одних спринтах и отсутствовать в других.

Отчёт автоматически определит текущий спринт на основе расположения файла и получит данные для этого спринта и двух
предыдущих.

## Подробности реализации

- Использует скрипт `dataset.js` для получения данных по задачам.
- Фильтрует задачи по той же логике, что и в представлении `task-report`.
- Реализует визуализацию с помощью HTML и CSS.
- Масштабирует столбцы по максимальному значению затраченного времени среди всех спринтов.
- Использует цветовую кодировку для различения спринтов (зелёный — текущий, синий — предыдущий, серый — самый ранний).
