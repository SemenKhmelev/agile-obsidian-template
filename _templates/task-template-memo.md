
> [!hint]- Памятка
> * `estimate_sprint` - время доступное в спринте на задачу. 
> * `estimate` - актуальна оценка времени по задаче. Может превышать `estimate_sprint`
> * `estimate (1st)` - изначальная оценка времени по задаче. Заполняется когда происходит первая переоценка задачи. 
> * `issue_task` - номер задачи во внешнем трекере
> * `issue_dp` - номер запроса на доработку во внешнем трекере
> * `activity` - возможное значение на выбор: feat, fix, devops, analysis, refactor, docs, test, chore, sd
> * `parent` - если есть родитель, значит задача является подзадачей другой задачи, эпика, темы или виденья
> * `previous` - ссылка на эту же задачу в предыдущем спринте
